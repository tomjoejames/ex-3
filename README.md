# Ex 3 – Simple Interactive Quiz

A 10-question multiple-choice quiz on HTML, CSS and JavaScript. Questions are shuffled, each has a 15-second timer, answers get instant correct/wrong feedback, the score updates live, and the result screen shows a full review with a Play Again button.

## Run on Windows (one click)

Double-click **`setup.bat`**. It opens `index.html` in your default browser.
No installs needed – this exercise uses only HTML, CSS and JavaScript.

## Run anywhere else

Open `index.html` in any modern browser.
